# Apostila PDF incluída no pacote

O novo pacote contém a apostila em:

```text
docs/apostila-portfolio-flask-igor-mota.pdf
```

Ela possui 27 páginas e foi organizada para estudo no VS Code. Os capítulos
explicam as ferramentas, a arquitetura, o caminho das requisições, o CRUD, o
login, a segurança, os uploads, os templates Jinja, o CSS, o Bootstrap, os
testes e a publicação.

## Assuntos práticos da apostila

- instalar e executar o projeto no Windows e no VS Code;
- adicionar, editar, ordenar e excluir projetos pelo painel;
- cadastrar links do GitHub, demonstração na nuvem e vídeo;
- alterar textos, cores, espaçamentos e responsividade;
- criar uma página de detalhes para cada projeto;
- filtrar projetos por categoria;
- criar um endpoint JSON;
- adicionar um campo novo do model até o template;
- evoluir artigos, análise de dados, PostgreSQL, Docker e deploy;
- testar, depurar e resolver erros comuns.

Comece por `00-START-HERE.md`, mantenha a apostila aberta ao lado do VS Code e
faça as práticas em uma branch de estudo.
